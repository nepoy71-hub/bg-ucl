# SYSTEM00000000 (PES 2021) - съдържание (2026-10-11)

Разшифроване: pesXdecrypter (github.com/the4chancup/pesXdecrypter), ключ PES21:
`gcc -O2 -fcommon -std=gnu99 -Wl,--allow-multiple-definition -DUSE_PES21_MASTER_KEY=1 -o dec21 src/decrypter.c src/crypt.c src/mt19937ar.c src/masterkey.c`
`dec21 SYSTEM00000000 out` -> data.dat (219 568 байта), description.dat ("System Data"), header, logo.png, version.txt.

## data.dat (натрупаният файл на потребителя)
- 0x00: заглавие: 16, 80, 219488 (размер), 10702, 700, 700, 0, 0, 70. 0x30-0x4F: 32 байта, изглеждат като хеш/ид.
- 0x80-0x153E0: слотове по 0xA0 с план за игра (схема: позиции x/y на 11-те, по 3 варианта; стойности 0x7F; списък с ид на играчи).
  Само първите 3 са попълнени: DUNAV RUSE (схеми + състав от 28 ид, сред тях 3650). Останалите ~285 са еднакви шаблони по подразбиране, ~95 са празни (ff).
  Планове на ДРУГИ отбори (противниците) няма.
- 0x15430-0x35800: сортирани списъци с ид (~31 300 общо; ид на играчи и др. с флагове 0x4000xxxx) - най-вероятно отметки "видяно/ново".
- 0x358D0: таблица с 16-битови числа (50, 75, 100, 12, 16, 20, 40, 75, 110, 30, 55, 80, 450, 800, 600, 900, 85, 400, 300, 70, 60, 400, 150, 400, 400, 800, 2500, 700, 1000, 140, 300, 300, 700, 500, 220, 1000), после 1 и -1024. Значение неизвестно.
- Не се вижда нищо, което прилича на брояч на победи/загуби, серия или резултати. Окончателно: само чрез сравнение със СВЕЖ файл (след изтриване и едно пускане), за да се видят байтовете, които растат с мачовете.
- Изтриването нулира и всички настройки в този файл (контроли, помощ при пас/удар, камера и др.) - това също трябва да се има предвид при сравнението.
